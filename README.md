# Posture Shimeji 🐱 — มาสคอตเตือนนั่งหลังค่อม (Windows)

โปรแกรมใช้เว็บแคมตรวจท่านั่ง แล้วมีมาสคอตสไตล์ Shimeji วิ่งเล่นบนหน้าจอ คอยเตือนเมื่อคุณนั่งหลังค่อม

| STATUS | ความหมาย | มาสคอตทำอะไร |
|---|---|---|
| `normal` | ท่านั่งดี | เดินเล่น นั่งพัก ปีนขอบจอ สีครีม ยิ้ม |
| `warning` | เริ่มค่อม | วิ่งไปมา หน้าเครียด เหงื่อตก มี bubble เตือนทุก ~12 วินาที |
| `bad` | หลังค่อมชัดเจน | ตัวใหญ่ขึ้น สีแดง วิ่งมากลางจอแล้วกระโดดเด้ง bubble กะพริบ + เสียงเตือน |
| `no_person` | ไม่พบคน | หลับ (zzz) |

สถานะปัจจุบันเขียนลง `%APPDATA%\PostureShimeji\status.txt` ด้วย (โปรแกรมอื่นอ่านต่อได้) และบันทึกใน `log.txt`

## เริ่มใช้งานใน 3 ขั้นตอน

1. แตกไฟล์ zip ไว้ที่ไหนก็ได้
2. **ดับเบิลคลิก `START.bat`** — ครั้งแรกจะติดตั้งให้เองอัตโนมัติ (5–10 นาที ทำครั้งเดียว ต้องต่ออินเทอร์เน็ต) ครั้งต่อไปเปิดทันที
   * ถ้ายังไม่มี Python จะมีข้อความบอกลิงก์ติดตั้ง **Python 3.11** (ติ๊ก *Add python.exe to PATH*) — ใช้ 3.13 ไม่ได้ เพราะ mediapipe รองรับถึง 3.12
3. ทำตามหน้าจอ: นั่งหลังตรงๆ มองกล้อง 5 วินาที เพื่อให้โปรแกรมจำ "ท่าที่ดีของคุณ" เสร็จแล้วมาสคอตจะคอยเตือนเอง

> อยากได้ไฟล์ `.exe` ไฟล์เดียว: ดับเบิลคลิก `build.bat` จะได้ `dist\PostureShimeji.exe` (ก๊อปไปไว้ที่ไหนก็ได้) หรืออัปโหลดขึ้น GitHub แล้วไปที่ Actions → *Build Windows exe* → Run workflow
> ถ้าวาง `PostureShimeji.exe` ไว้โฟลเดอร์เดียวกับ `START.bat` ดับเบิลคลิก `START.bat` จะเปิด exe ให้เลย
> ไฟล์ exe ขนาด 300+ MB และเปิดครั้งแรกอาจใช้เวลา 10–30 วินาที

## หน้าต่างควบคุม (ใช้งานทุกอย่างจากที่เดียว)

**คลิกไอคอนที่ system tray** (มุมขวาล่างข้างนาฬิกา) เพื่อเปิด/ปิดหน้าต่างควบคุม ซึ่งมี

| ส่วน | ใช้ทำอะไร |
|---|---|
| การ์ดสถานะ | ดูว่าตอนนี้นั่งท่าดีหรือค่อม พร้อมแถบระดับความหลังค่อม (เขียว/ส้ม/แดง) |
| ▶ เริ่ม / ⏸ หยุดตรวจจับ | ปุ่มใหญ่ปุ่มเดียว เปิด-ปิดกล้อง |
| 🎯 ปรับท่านั่งมาตรฐาน | ใช้เมื่อย้ายกล้อง/เก้าอี้แล้วรู้สึกเพี้ยน |
| 📷 ดูภาพกล้อง | ดูว่ากล้องเห็นใบหน้าและไหล่ครบไหม |
| ตั้งค่า | ความไว (ผ่อนปรน/ปกติ/เข้มงวด), เสียงเตือน, เปิดพร้อม Windows, เลือกกล้อง |
| มาสคอต | สลับระหว่าง "ตัวเดิม (แมวส้ม)" กับ "รูปของฉัน" ได้ทุกเมื่อ, เลือกไฟล์ PNG ใหม่, ปุ่มลองดูท่าทางแต่ละสถานะ |
| เสียง | เปิด/ปิดเสียง, ความดัง (เบา/กลาง/ดัง), ปุ่มลองฟังเสียงเตือน |

คลิกขวาที่มาสคอตหรือไอคอน tray จะได้เมนูสั้นๆ (เปิดหน้าต่างควบคุม / หยุดชั่วคราว / ปรับท่านั่ง / ออก)
ปิดหน้าต่างควบคุมแล้วโปรแกรมยังทำงานต่อ ลากมาสคอตด้วยเมาส์ได้ คลิกเฉยๆ จะมีคำพูด

กล้องควรเห็น **ใบหน้า (หู) และไหล่ทั้งสองข้าง** ตั้งไว้หน้าจอตรงๆ หรือเฉียงเล็กน้อยก็ได้

## ตัวละคร (เปลี่ยนได้ ไม่ต้องลบตัวเก่า)

หน้าต่างควบคุม → ส่วน **มาสคอต** กดเลือกได้ทันที (มีรูปตัวอย่างบนปุ่ม):

| ตัวละคร | จุดเด่น |
|---|---|
| 🐱 แมวส้ม | ตัวอ้วนกลม เส้นขอบดำ หางลายขวาง ตาโต |
| 🐰 กระต่ายชมพู | หูยาวตามอารมณ์ (ตกเวลาเตือน) ดอกไม้ที่หู ฟันหน้า แก้มชมพูฟู |
| 🐶 ชิบะ | ผ้าพันคอเขียวลายจุด หน้าครีม จุดคิ้ว หางม้วนฟู |
| 🦝 แรคคูน | **ใหม่!** ตามภาพอ้างอิง: หน้ากากสีเข้มขอบขาว ปากขาว ท้องขาว หางลายวงปลายดำ อุ้งมือ/เท้าสีดำ ยกมือจับคางเป็นท่าประจำตัว |
| 🖼 รูปของฉัน | ใช้ไฟล์ PNG ของคุณเอง (ปุ่มจะกดได้เมื่อเคยเลือกรูปไว้) |

ทุกตัวมีครบทุกอารมณ์ (ปกติ / เตือน / หลังค่อม / ไม่พบคน) เสียงร้องไม่เหมือนกัน (เมี้ยว / ปิ๊บ / โฮ่ง / จี๊ดๆ) และจำตัวที่เลือกไว้ตอนเปิดครั้งหน้า
เปลี่ยนตัวละครแล้วรูป PNG ที่เคยเลือกไว้ไม่หาย กด 🖼 กลับมาใช้ได้ทุกเมื่อ

## เสียง

| เหตุการณ์ | เสียง |
|---|---|
| เริ่มค่อม (warning) | โน้ตเตือนเบาๆ ทุก ~12 วินาที |
| หลังค่อมชัดเจน (bad) | **ไซเรนดังต่อเนื่อง จนกว่าจะนั่งตรง** (หรือพัก/ปิดเสียง) |
| กลับมานั่งดี | ติ๊งๆๆ |
| ปรับท่านั่งเสร็จ | เสียงอาร์เพจจิโอสั้นๆ |
| คลิกมาสคอต | เมี้ยว~ |

ถ้าไซเรนดังอยู่แล้วต้องเงียบด่วน (เช่นเข้าประชุม): **คลิกที่มาสคอต** = พักเสียง 1 นาที, หรือกด "หยุดตรวจจับ", หรือปิดเสียงในหน้าต่างควบคุม

## ใช้รูปมาสคอตของตัวเอง / กลับไปตัวเดิม

หน้าต่างควบคุม → ส่วน **มาสคอต** → **📂 เลือกไฟล์รูปใหม่** (PNG พื้นโปร่งใส หันหน้าไปทางขวา) แล้วเลือกว่าใช้กับสถานะไหน (หรือ "ทุกสถานะ" ง่ายที่สุด) เปลี่ยนทันที
อยากกลับไปแมวส้มตัวเดิม กด **🐱 ตัวเดิม** ได้เลย ไม่ต้องลบอะไร (รูปของคุณยังเก็บไว้ กด **🖼 รูปของฉัน** เพื่อกลับมาใช้ได้อีก)
ขั้นสูง: วางไฟล์ `normal.png`, `warning.png`, `bad.png`, `no_person.png` ในโฟลเดอร์ `sprites` เองก็ได้

## ฟีเจอร์ใหม่ใน v8

### 📊 สถิติท่านั่ง
**สถิติรวมอยู่ในหน้าต่างเดียวกับหน้าควบคุมแล้ว** (ไม่มีหน้าต่างแยก):
- กด **"📊 ดูสถิติ"** (หรือคลิกขวาที่มาสคอต → สถิติท่านั่ง) หน้าต่างจะขยายกว้างออก โชว์สถิติทางขวาของตัวควบคุม กดอีกครั้ง ("◂ ซ่อนสถิติ") เพื่อหุบกลับ
- หรือกดปุ่ม **ขยายเต็มจอ** ของหน้าต่างเลย สถิติจะโผล่ทางขวาเอง ฝั่งตัวควบคุมกว้างคงที่ ปุ่มไม่ยืด
- ยิ่งหน้าต่างกว้าง กราฟยิ่งวางเคียงกันหลายคอลัมน์ (แคบ = 1 คอลัมน์ / กว้าง = 2 / เต็มจอใหญ่ = 3) และตัวเลขสรุปเรียงเป็น 4 ช่อง

ในหน้าสถิติจะเห็น
- คะแนนท่านั่ง % ของวันนี้ / 7 วัน / 30 วัน พร้อมเทียบกับช่วงก่อนหน้า
- กราฟแท่งรายชั่วโมง (วันนี้) หรือรายวัน แยกสี นั่งดี / เตือน / ค่อม (เอาเมาส์ชี้แท่งเพื่อดูรายละเอียด)
- ข้อสังเกต เช่น ช่วงเวลาที่ค่อมบ่อยสุด และ **สาเหตุหลัก** (หัวก้ม / คอยื่น / โน้มตัวเข้าจอ / ไหล่เอียง) พร้อมคำแนะนำ
- ส่งออก CSV ได้ ข้อมูลเก็บในเครื่องที่ `%APPDATA%\PostureShimeji\stats.json` (เก็บย้อนหลัง 120 วัน) และจะส่งขึ้นเว็บก็ต่อเมื่อคุณเปิด "🌐 ส่งสถิติขึ้นเว็บ" เอง (ดูหัวข้อถัดไป)

### 📊 แดชบอร์ดสถิติแบบละเอียด (v10)
หน้าสถิติเพิ่มข้อมูลเชิงลึกหลายอย่าง (เลือกดู วันนี้ / 7 วัน / 30 วัน)
- **เป้าหมาย 70%**: บอกว่าถึงเป้าหรือยัง อีกเท่าไหร่ และ 🔥 **ทำเป้าติดต่อกันกี่วัน**
- **การ์ดตัวเลข 8 ช่อง**: เวลาที่ตรวจจับรวม, เฉลี่ยต่อวัน, **คะแนนความค่อมเฉลี่ย (0-100 ยิ่งต่ำยิ่งดี)**,
  **นั่งดีต่อเนื่องนานสุด**, **นั่งนานสุดโดยไม่ลุก**, **ลุกพักกี่ครั้ง** (ออกจากหน้ากล้องเกิน 2 นาที),
  **ค่อมชัดเจนกี่ครั้ง + แก้ท่าเฉลี่ยครั้งละกี่วินาที**
- **แนวโน้มคะแนนรายวัน** (เส้นกราฟ + เส้นเป้าหมาย) สำหรับ 7 / 30 วัน
- **ยิ่งนั่งนาน ท่ายิ่งแย่ไหม?** เทียบคะแนนช่วง 0-30 / 30-60 / 60-90 / 90+ นาทีของแต่ละรอบการนั่ง
- **สาเหตุที่ทำให้ค่อมครบทั้ง 4 อย่าง** เป็นแท่งสัดส่วน พร้อมคำแนะนำของสาเหตุหลัก
- **Heatmap วัน × ชั่วโมง** ดูว่าวันไหน/ชั่วโมงไหนนั่งดีหรือแย่ (เอาเมาส์ชี้ดูรายละเอียด)
- ข้อสังเกตเพิ่ม เช่น เตือนให้ลุกเมื่อนั่งต่อเนื่องเกิน 1 ชม. และบอกถ้า "นั่งนานแล้วท่าแย่ลง"
- **🧾 ส่งออก JSON** รายวันแบบละเอียด (schema 1) เตรียมไว้ต่อยอดเป็น dashboard บนเว็บ ได้แก่
  `date, tracked_s, good_s, warning_s, bad_s, away_s, good_ratio, avg_penalty, longest_good_streak_s,
  longest_sitting_s, sessions, breaks, bad_episodes, avg_bad_episode_s, alerts, pet, snack, causes, hourly[24]`

ข้อมูลที่เพิ่มเริ่มเก็บตั้งแต่เปิด v10 (ข้อมูลเก่าใน `stats.json` ยังอ่านได้ปกติ แต่ช่องที่ต้องใช้ข้อมูลใหม่ เช่น ลุกพัก / นั่งนานสุด จะนับจากวันที่อัปเดตเป็นต้นไป)

### 🌐 ส่งสถิติขึ้นเว็บ (เรียลไทม์)
ปิดไว้เป็นค่าเริ่มต้น เปิดได้ที่ปุ่ม **"🌐 ส่งสถิติขึ้นเว็บ…"** ในหน้าต่างควบคุม
1. deploy โฟลเดอร์ `web/` (ดู `web/README.md`) ขึ้น Netlify **ครั้งเดียว** ทุกคนใช้เว็บเดียวกันได้ ไม่ต้องตั้งตัวแปรลับ
2. แต่ละคนกดปุ่มในแอป → ใส่ URL เว็บ → กด **ทดสอบการเชื่อมต่อ** → ติ๊กเปิด → บันทึก
3. กด **"🌍 เปิดแดชบอร์ดในเบราว์เซอร์"** เบราว์เซอร์จะเปิดเว็บพร้อมรหัสส่วนตัวของคุณให้อัตโนมัติ (ดูได้เฉพาะข้อมูลของตัวเอง)
4. แอปจะส่งสถานะสดทุก ~10 วินาที (และทันทีที่สถานะเปลี่ยน) ส่งประวัติย้อนหลัง 60 วันทุก ~5 นาที

ส่งเฉพาะตัวเลขสรุป (เวลาดี/เตือน/ค่อมรายชั่วโมง สาเหตุ จำนวนครั้งที่เตือน เหตุการณ์ล่าสุด) **ไม่ส่งภาพจากกล้อง** แต่ละเครื่องมี "รหัสส่วนตัว" ที่แอปสุ่มให้ ส่งผ่าน HTTPS ใน `Authorization: Bearer` เซิร์ฟเวอร์เก็บข้อมูลแยกตาม hash ของรหัสนั้น
ค่าที่ตั้งเก็บใน `%APPDATA%\\PostureShimeji\\config.json` (`web_on`, `web_url`, `web_key`, `web_invite`) ซอร์สส่วนนี้อยู่ใน `web_sync.py`

### 🐾 มาสคอตมีชีวิตมากขึ้น
- **นั่งบนขอบหน้าต่าง**: ตอนนั่งท่าดี มาสคอตจะกระโดดขึ้นไปนั่ง/เดินบนขอบบนของหน้าต่างโปรแกรมอื่น ตามหน้าต่างเวลาลาก และตกลงมาถ้าหน้าต่างหาย
  (ใช้ ctypes อ่านตำแหน่งหน้าต่างเอง ไม่ต้องติดตั้งอะไรเพิ่ม ถ้าจอมีสเกลต่างกันหลายจออาจเพี้ยนเล็กน้อย)
- **ตามเมาส์**: บางครั้งเดินตามเมาส์ และทักเมื่อเมาส์มาอยู่ใกล้ๆ นานๆ
- ปิดสองอย่างนี้ได้ที่ติ๊ก "ให้มาสคอตกระโดดขึ้นนั่งบนขอบหน้าต่าง และตามเมาส์"
- พอท่านั่งเริ่มแย่ มาสคอตจะเลิกเล่นทุกอย่างแล้วกลับมาเฝ้าท่านั่งทันที

### 🕐 ทักทายตามเวลา
เช้า / เที่ยง / เย็น ทักวันละครั้ง ช่วงดึก (23:00–04:00) มาสคอตจะง่วง หาว งีบบ่อยขึ้น และเตือนให้นอนทุก ~40 นาที
กลับมาหน้าจอหลังหายไปเกิน 10 นาทีจะมีคำต้อนรับ (ปิดได้ที่ติ๊ก "ทักทายตามเวลา")

### 👯 ตัวละครคู่หู
เลือก "ตัวละครคู่หู" ในส่วนมาสคอต จะมีสองตัวอยู่ด้วยกัน ตัวคู่หูไม่เตือนท่านั่ง แต่ทำสถานะตามตัวหลัก
และบางครั้งสองตัวจะ **วิ่งไล่จับกัน** หรือหันหน้าคุยกัน

### 🤲 ลูบหัว และ 🍪 ป้อนขนม
- **กดค้างที่ตัวมาสคอต** (ไม่ขยับเมาส์) = ลูบหัว มีหัวใจลอย (ลากตัวเมื่อไหร่ก็ยังได้เหมือนเดิม)
- ปุ่ม "🍪 ให้ขนมมาสคอต": ขนมจะตกลงมา (ปลา/แครอท/กระดูก/คุกกี้ตามตัวละคร) **ลากไปวางที่ตัวมาสคอต** หรือปล่อยไว้ให้มาสคอตเดินมากินเอง
  มาสคอตจะกินเฉพาะตอนนั่งท่าดีเท่านั้น

### 📏 ขนาดตัวละคร และ 📷 ชื่อกล้อง
- ปรับขนาดมาสคอตได้ 40%–200% ด้วยแถบเลื่อนในส่วนมาสคอต กดปุ่ม "กลับเป็นขนาดเดิม" เพื่อคืนเป็น 100%
- ช่องเลือกกล้องแสดงชื่ออุปกรณ์จริง (อ่านจาก DirectShow) กด 🔄 เพื่อค้นหาใหม่ ถ้าอ่านชื่อไม่ได้จะแสดงเป็น "กล้องตัวที่ N"
- ช่องเลือก/แถบเลื่อนจะไม่เปลี่ยนค่าเวลาเลื่อนลูกกลิ้งเมาส์ผ่าน ต้องคลิกเลือกเท่านั้น

### 🌏 ภาษา และ 🎨 ธีม
สลับ ไทย / English และธีม สว่าง / มืด / ซากุระ ได้ในส่วน "ตั้งค่า" มีผลทันที

## ตรวจจับยังไง

ใช้ **MediaPipe Pose (33 keypoints)** ตัวเดียวกับที่ `MindDock/motion-tracker` ใช้เป็น backend หลัก แต่ repo นั้นออกแบบสำหรับ macOS/Apple Silicon จึงเขียนส่วนวิเคราะห์ท่านั่งใหม่ให้รันบน Windows โดยดูจาก

1. **หัวจมลงเทียบกับไหล่** (ระยะหู→ไหล่ ต่อความกว้างไหล่) — น้ำหนัก 45%
2. **คอยื่นไปข้างหน้า** (มุมจาก world landmarks 3D) — 25%
3. **โน้มตัวเข้าหาจอ** (ไหล่ใหญ่ขึ้นในภาพ) — 25%
4. **ไหล่เอียง** — 15%

รวมเป็นคะแนน 0–1 เทียบกับท่ามาตรฐานที่ calibrate แล้วใช้ค่าเฉลี่ยเลื่อน + หน่วงเวลา (warning ≥ 4 วิ, bad ≥ 5 วิ) กันมาสคอตตกใจเวลาก้มหยิบของแป๊บเดียว
ค่าปรับได้ที่ต้นไฟล์ `posture_shimeji.py` (`WARN_TH`, `BAD_TH`, `ENTER_DELAY`)

ทุกอย่างประมวลผลบนเครื่อง ไม่ส่งภาพออกอินเทอร์เน็ต (ประมวลผล ~10 เฟรม/วินาที)

> โปรแกรมนี้เป็นเครื่องมือช่วยเตือนสร้างนิสัย ไม่ใช่อุปกรณ์ทางการแพทย์

## แก้ปัญหา

* **เปิดกล้องไม่ได้** — ปิดโปรแกรมที่ใช้กล้องอยู่ (Zoom/Teams) และเช็ก Settings → Privacy → Camera → อนุญาตแอปเดสก์ท็อป หรือเลือกกล้องตัวอื่นในหน้าต่างควบคุม
* **Windows SmartScreen เตือน** — เพราะ exe ไม่มีลายเซ็นดิจิทัล กด More info → Run anyway
* **Antivirus ลบ/บล็อก exe** — เกิดได้กับไฟล์ที่ build ด้วย PyInstaller ให้เพิ่มข้อยกเว้น หรือใช้ `START.bat` (รันจากซอร์สโค้ด ไม่ใช่ exe) แทน
* **เตือนเร็ว/ช้าไป** — ปรับ "ความไวในการเตือน" ในหน้าต่างควบคุม หรือกดปรับท่านั่งมาตรฐานใหม่
