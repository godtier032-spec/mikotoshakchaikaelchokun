# Posture Shimeji — Web dashboard (Netlify, หลายผู้ใช้)

หน้าเว็บ static (`public/index.html`) + 2 Netlify Functions ที่เก็บข้อมูลด้วย Netlify Blobs
**deploy ครั้งเดียว ทุกคนใช้ลิงก์เดียวกัน** แต่ละคนเห็นเฉพาะข้อมูลของตัวเอง

```
แอปของแต่ละคน --POST /api/ingest (Bearer <รหัสส่วนตัว>)--> Function --> Blobs: device/<sha256(รหัส)>
เบราว์เซอร์    <--GET  /api/stats  (Bearer <รหัสส่วนตัว>)--  Function <-- Blobs: device/<sha256(รหัส)>
```

รหัสส่วนตัว = สตริงสุ่ม 32 ตัวอักษรที่แอปสร้างให้เองในแต่ละเครื่อง (ไม่ต้องสมัครสมาชิก)
เซิร์ฟเวอร์ไม่เก็บตัวรหัส เก็บแค่ hash ใครไม่มีรหัสก็เดา/เปิดดูข้อมูลของคนอื่นไม่ได้

## Deploy

> Functions ใช้ไม่ได้กับการลากโฟลเดอร์วาง (drag & drop) ต้อง deploy จาก Git หรือ Netlify CLI

**ทางที่ 1: Git (แนะนำ)**
1. push โฟลเดอร์ `web/` นี้ขึ้น GitHub (เป็น root ของ repo)
2. Netlify → Add new site → Import from Git → เลือก repo (ค่า build อ่านจาก `netlify.toml` เอง)
3. จบ — ไม่ต้องตั้งตัวแปรใดๆ

**ทางที่ 2: CLI**
```
npm i -g netlify-cli
cd web && npm install
netlify login && netlify init
netlify deploy --prod
```

**(ทางเลือก) รหัสเชิญ** ถ้าไม่อยากให้คนแปลกหน้าที่รู้ URL สร้างข้อมูลในไซต์ได้
Site configuration → Environment variables → เพิ่ม `INVITE_CODE` = รหัสอะไรก็ได้ แล้ว deploy ใหม่
จากนั้นแจกรหัสเชิญให้เพื่อนๆ ให้กรอกในแอป (ช่อง "รหัสเชิญ")

## วิธีใช้ (ของแต่ละคน)
1. แอป → "🌐 ส่งสถิติขึ้นเว็บ…" → ใส่ `https://<ชื่อไซต์>.netlify.app` → ทดสอบการเชื่อมต่อ → ติ๊กเปิด → บันทึก
2. กด "🌍 เปิดแดชบอร์ดในเบราว์เซอร์" ในแอป เว็บจะรับรหัสส่วนตัวจาก URL (`#k=...`) เก็บไว้ใน localStorage ของเบราว์เซอร์นั้น แล้วล้างออกจาก URL
   * เปิดบนมือถือ/เครื่องอื่น: กด "📋 คัดลอกรหัส" ในแอป แล้ววางที่หน้า "เชื่อมต่อ" ของเว็บ
3. หน้า "แดชบอร์ด" ขึ้น ● LIVE ภายใน ~10 วินาที ถ้าแอปหยุดส่งเกิน 45 วินาทีจะขึ้น OFFLINE

เปิดดูหน้าตาโดยไม่ต้องต่อแอป: ต่อท้าย URL ด้วย `?demo` (ข้อมูลสุ่ม)

## ความปลอดภัย
* ทุกคำขอต้องมี `Authorization: Bearer <รหัสส่วนตัว>` ผ่าน HTTPS รหัสต้องเป็น `A-Za-z0-9_-` ยาว 24–128 ตัว
* ข้อมูลเก็บแยกที่ `device/<sha256(รหัส)[:32]>` แต่ละรหัสอ่านได้เฉพาะของตัวเอง
* `/api/ingest` จำกัดขนาดคำขอ 600 KB, ส่งถี่กว่า 1.5 วินาทีต่อรหัสจะได้ 429
* ถ้ารหัสรั่ว: กด "สุ่มรหัสใหม่" ในแอป (ข้อมูลเก่าที่ผูกกับรหัสเดิมจะไม่แสดงอีก)
* ข้อมูลที่เก็บ: ตัวเลขสรุปย้อนหลัง 120 วันต่อรหัส ไม่มีภาพ

## แก้ปัญหา
| อาการ | สาเหตุ |
|---|---|
| ทดสอบในแอปได้ `HTTP 403 invite code required` | เจ้าของไซต์ตั้ง INVITE_CODE ไว้ กรอกรหัสเชิญในแอปให้ตรง |
| `HTTP 404` | URL ผิด หรือยังไม่ได้ deploy แบบมี Functions (ไม่ใช่ drag & drop) |
| `HTTP 401 bad key` | รหัสส่วนตัวผิดรูปแบบ กด "สุ่มรหัสใหม่" ในแอป |
| `HTTP 429` | ส่งถี่เกินไป ลองใหม่ใน 2–3 วินาที |
| เว็บขึ้น "ใส่รหัสส่วนตัว…" | ยังไม่ได้เปิดเว็บผ่านปุ่ม "เปิดแดชบอร์ด" ในแอป หรือยังไม่ได้วางรหัส |
| เว็บขึ้น "ยังไม่มีข้อมูลจากรหัสนี้" | แอปยังไม่เคยส่งสำเร็จด้วยรหัสนี้ (หรือรหัสในเว็บไม่ตรงกับในแอป) กดทดสอบการเชื่อมต่อในแอป |
